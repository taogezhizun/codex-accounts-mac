# 使用指南

## 支持范围

macOS 14+、Swift 5.9+ / Xcode 15+。优先在 Apple Silicon 上验证；Intel 可构建，但尚未进行实机验收。

需要安装官方 Codex 桌面 App。工具通过应用标识 `com.openai.codex` 发现 App，支持应用文件名称变化；使用 App 内置的 Codex 可执行程序，不随包再分发 OpenAI 程序。

第一版支持 ChatGPT 登录凭据，以及 `CODEX_HOME/auth.json` 文件认证（默认目录 `~/.codex`）。**暂不支持** API Key、`keyring` / `auto` / `ephemeral` 认证、共享 app-server 守护进程或受管理的认证策略。检测到这些不兼容情况时会停止切换。设置中的认证目录必须与桌面 App 实际使用的一致。

本工具不会自动判断所有正在运行的任务。点击切换后，需要先确认任务已暂停；如果 App 拒绝退出或其已识别的 Codex 子进程仍在运行，则停止切换，不强制结束桌面进程。其他客户端共用同一认证目录时也可能受到影响。

## 从源码构建

在仓库根目录运行：

```sh
./scripts/build-app.sh
open "dist/Codex Accounts.app"
```

将生成的 `.app` 拖入“应用程序”即可自用。脚本使用本地 ad-hoc 签名，无需付费 Apple Developer 账号。它不是 Developer ID 签名或 Apple 公证；其他机器下载未公证产物时可能出现 Gatekeeper 提示。也可以选择从源码在本机构建。

保存凭据等操作可能需要钥匙串授权。打开工具和查看额度无需读取钥匙串，详见下方[钥匙串与授权](#钥匙串与授权)。

## 应用内更新

0.3.0 起，点击菜单栏应用菜单或“设置 → 应用更新 → 检查更新…”。发现新版后确认安装，Sparkle 会替换正在使用的工具并重新打开。只重开本工具，账号、备注、钥匙串和 Codex 桌面 App 保持原位。

**0.2.x 需要最后手动升级一次**：退出旧工具，把新版本拖到“应用程序”，替换同名 App，之后从同一位置启动。不要从下载压缩包或只读磁盘映像里长期运行。更新采用 HTTPS、Ed25519 签名和提取前校验，签名私钥不在仓库中；它不等于 Apple 公证。升级后下次主动管理保存的凭据时，macOS 可能重新请求钥匙串授权；0.3.2 起，启动与额度刷新不会触发本工具的钥匙串访问。

## 首次使用

1. 在设置中确认桌面 App 和认证目录。
2. 点击“保存当前账号”，保留目前的登录。
3. 点击“浏览器添加账号”，在 OpenAI 官方页面登录另一个自己的账号；添加不会切换当前桌面账号。
4. 暂停桌面中的任务后，选择新账号并点击“切换至此账号…”，核对来源与目标后确认“切换并重开”。
5. 在重新打开的桌面 App 中核对账号，再点击工具中的“已核对，账号正确”；失败时使用“恢复上次认证”。

自动刷新默认开启：启动后只刷新与 Codex 当前登录匹配的已保存账号，正常间隔 5 分钟，唤醒后补刷。其他账号只显示上次缓存，手动刷新入口也禁用；切换并核对后再更新。失败按 10、20、40、60 分钟退避，恢复成功后回到 5 分钟。登录、切换、待核对和应用更新期间暂停自动刷新。设置中可以关闭，⌘R 可立即刷新选中的当前账号。

额度查询使用隔离辅助进程和 externally managed token 模式，不在第二个进程中刷新保存的 refresh token。查询前后会核对当前登录文件中的账号身份，避免把结果写入另一个账号。工具不会发送预热消息、消费额度重置券或进行自动轮换。

## 钥匙串与授权

**以下行为适用于 0.3.2 及之后版本。** 已保存账号的凭据和恢复备份仍保存在 macOS 钥匙串；当前额度查询使用 Codex 的登录文件，两者用途不同。

| 操作 | 数据来源与授权 |
| --- | --- |
| 启动工具、打开窗口、浏览账号 | 读取本地账号列表、额度缓存与当前登录身份，不访问钥匙串 |
| 手动或自动刷新当前账号额度 | 读取当前 Codex 登录文件，不访问钥匙串，也无需先检查恢复记录 |
| 保存、导入或移除账号 | 主动读写保存的凭据，macOS 可能请求钥匙串授权 |
| 确认切换、恢复认证、检查恢复记录或确认核对结果 | 主动读写钥匙串中的凭据或恢复记录，macOS 可能请求授权 |

确认切换后，工具会先检查恢复记录。若发现上次切换尚待核对、记录无法读取或授权被取消，会在退出 Codex 桌面 App 前停止。重启工具后，恢复记录留到你主动切换或恢复时再检查；可从「更多操作 → 恢复上次认证…」读取备份。

升级或自行重新构建后，签名身份变化可能让系统在下一次主动访问钥匙串时再次询问。0.3.1 曾有启动时读取恢复记录并弹窗的问题，已在 0.3.2 移除该读取。若旧版弹窗挡住界面，可以点「拒绝」后进入「设置 → 应用更新 → 检查更新…」升级。

## 日常操作

菜单栏点击目标账号即可就地确认切换；当前认证置顶，点击它可打开桌面 App。账号列表支持滚动和搜索，不限于前五个账号。额度旁的时钟表示缓存需要刷新。摘要取 Codex 各周期中最低的剩余比例；没有 Codex 数据时显示未读取，不借用其他额度组。

额度详情优先显示接口的易读名称，Codex 排在前面。未知组默认折叠到“其他额度”，原始编号可点击 ⓘ 查看。不同组不能合并或视为可互相替代。旧缓存可直接使用；刷新后可获得接口提供的新名称。

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 浏览器添加账号 |
| ⌘R | 刷新选中的当前账号额度 |
| ⌘↩ | 查看选中账号的切换确认 |
| ⇧⌘P | 隐藏或显示邮箱 |
| ⌘E | 编辑选中账号的备注 |

隐藏邮箱不等于可安全公开截图：备注仍然可见。公开素材始终使用演示模式。
